another FDE should be able to read this and understand what was intended,
what was built, what was verified, and what remains open — without
reading the code first.

decide it means? Link to the relevant sections of `docs/PRD.md`,

passes. Reference `npm run verify` output if used._

## Known limitations

anything already listed in `docs/security-checklist.md`'s baseline

further than this prototype (see `docs/security-checklist.md`)._
